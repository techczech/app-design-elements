5. Shortcut cheat sheet ⌘/

Lists every shortcut as it is set now, including your own changes, and opens while you are typing.

The rule in detail

Reserved chords

ChordSurfaceTier
⌘⇧PCommand palettealways
⌘KContextual actions on the selectionalways
⌘,Settingsalways
⌘/Cheat sheet, works while typingalways
⌘⇧,Rebind highlighted palette commandalways
⌘F / ⌘⇧FFind in document / search everythingdefault-on
⌘⇧KNavigation switcherwhen journeys need it
⌘PPreview / inspectorwhen journeys need it

⌘K is deliberately not the web's switcher or insert-link. Link moves to ⌥⌘K (displaced action keeps its letter, gains a modifier).
