# App design elements

Every Mac app I build has the same sixteen elements. If you know how to use one of my apps, you already know how to use the next: the same keyboard shortcuts open the same things, the menus are laid out the same way, and Settings looks the same.

Each command in an app is defined once, in one list. The command palette, the menu bar, the cheat sheet of keyboard shortcuts and the list of actions an AI agent can ask the app to perform are all built from that list, so they always agree. If you change a shortcut in Settings, the menu bar and the cheat sheet show the new one.

An app differs from the others only where its subject requires it, and the difference is written down. Anything an app can do with your content, an AI agent can do too, using the same actions the buttons and menus use. An agent can also read and change settings, and each change it makes appears in the list of changes you see in Settings.
