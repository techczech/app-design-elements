▾ What this does
TalkWeaver adds a small set of instructions for each agent you tick, so the agent knows how to use TalkWeaver. It writes these folders and nothing else:
  • ~/.claude/skills/talkweaver for Claude Code
  • ~/.agents/skills/talkweaver for Codex
  • ~/.gemini/antigravity/skills/talkweaver for Antigravity
It also adds a command-line tool, talkweaver, which the agents run to work on your presentations. T3 Code uses the Claude Code and Codex copies.
Connected copies are updated with each TalkWeaver update. You can remove them at any time in Settings, under Agents.
