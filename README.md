# App Design Elements

App Design Elements is Dominik Lukeš's maintained app-patterns skill. It records his requirements for consistent desktop commands, purpose groups, keyboard access, menus, Settings, help, layout and app behaviour. Its development combines Dominik's decisions, work on his apps, and explicitly acknowledged lessons from other authors.

**This skill is distinct from the external skills used alongside it.** Installing or consulting another author's skill does not make that skill Dominik's work.

## What belongs to which category

| Category | What it means here |
|---|---|
| Dominik's app patterns | The maintained requirements and their local synthesis, including the command registry, reserved command surfaces, visible command-purpose groups, core/supplementary priority, the two-top-bar rule and the owner-supplied window-control examples. |
| External skills imported as external skills | Impeccable by pbakaus and contributors; Microsoft's winui-design, winui-code-review and winui-ui-testing. These have their own authors, pinned imports, READMEs, licences and notices. Their complete source is not bundled into this skill. |
| Lessons adapted into this skill | Independently maintained English guidance informed by external reading. The source, author, affected section and nature of the adaptation are recorded in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md). |
| Research-only material | Other skill packs inspected for ideas. Reading a source does not install it, endorse all its rules or adopt its workflow. Desktop Taste Skills remains in this category; only the lessons listed in the notice were incorporated. |

## Attribution and licences

[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) is the human-readable source and adaptation ledger. [third-party-licenses/](third-party-licenses/) preserves the inspected upstream licence and notice texts. The [MIT licence](LICENSE) covers the original contributions to this skill; it does not erase upstream copyright, notices or separately applicable terms.

The notices identify conceptual learning and independently rewritten criteria separately from copied upstream files. Where an external pack is installed whole, use its own upstream name and credit. Do not package it as a Dominik-authored skill or put his copyright over its existing notice.

## Current external complements

**Impeccable** is the first external UI-review tool, normally using its Operate mode for app surfaces. **Microsoft's WinUI skills** complement it for Windows-specific work in their stated framework scope. The WinUI design/code-review instructions do not apply wholesale to Electron or Tauri. Installing the instruction files does not install Windows prerequisites or establish Windows runtime acceptance.

The Mac-and-Windows platform contract and the app-patterns rules remain the product requirements. External reviews provide evidence and suggestions against them. No complete third-party skill pack is embedded in these requirements.

## Publication

This README, THIRD-PARTY-NOTICES.md and third-party-licenses/ are distributable parts of the skill and must travel together in a published copy. Private provenance files and raw research are not substitutes: the publishing workflow intentionally excludes PROVENANCE.md and private design records. The external skill installations remain private and have no publishing manifests.

Publication still uses the existing review-and-approval workflow. This documentation update does not publish a new public version.
